# p007-C8-day1-assignment-quiz
Interactive python code generated using AI prompting techniques of roleplay, few shots prompting, context dump. Program accepts an input of any topic of user choice and generates a quiz of 10 questions with MCQ responses. Based on user choice, it gives feedback and finally a score. sky is the limit for topics that user can pass as input
can be run as standalone app. run python quiz_app.py
can be run as a webpage. run python app.py and then the webpage url will be provided
